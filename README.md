# Bobo's Journey

A 3D vertical platformer about Bobo- a ball, which has to bounce back.

Made in Unity 6 (6000.3.10f1), Built-in render pipeline, new Input System.

## Running it
There are 2 ways to play-
1) Just play on itch! (https://aditya-gamer11.itch.io/bobos-journey)
2) Import the game to unity, and build it for windows (or macos)

## Controls
WASD --> Move\
Mouse --> Camera angle\
Space --> Jump\
R --> Back to last flag/checkpoint\
Esc --> Menu/Pause

## Lore
Bobo lived in Ball world with his Ball parents. However, one unfateful day, the ball king had both his parents killed- for reasons not yet known. With his dying breath, Bobo's dad used some mysterious power to send Bobo somewhere- to save him from the evil king. Bobo must learn to survive, with only his father's final words to guide him- Bounce Back.

## Graphics settings
Had to add these since my laptop is kinda cooked.
It features 3 graphics settings- Fast, Balanced, and Fancy (self explanatory names). You can change between them anytime using the menu.
The primary differences between the 3 are render resolution, moon shadows, lighting (per pixel), fog effects, and some detailing.
